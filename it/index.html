p7m-apri

Aprire file .p7m e fatture elettroniche

Estrai il documento da un file firmato digitalmente .p7m e verifica la firma, senza installare nulla. Trasforma le fatture elettroniche FatturaPA (XML o .p7m) in un PDF leggibile. I file vengono cancellati dopo un'ora.
